# 🌺 Maa Durga — A Code-Born Story

An interactive visual storytelling website dedicated to **Maa Durga**, celebrating her divine form and the spirit of Dussehra through artistic illustrations, animations, and a beautiful web experience.

## ✨ Features

- 🎨 **Divine Line-Art Illustration** — Custom artwork inspired by Maa Durga.
- 📖 **Visual Storytelling** — Four illustrated chapters that bring the story to life.
- 🪷 **Devotional Experience** — A carefully designed interface celebrating the power and grace of Maa Durga.
- 🎭 **Elegant Visual Design** — Custom styling, smooth visual transitions, and engaging presentation.
- 📱 **Responsive Interface** — Designed for a modern web browsing experience.
- ⚡ **Modern Web Technology** — Built with React, TypeScript, and Vite.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | User interface |
| TypeScript | Type-safe development |

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/).

### 1. Clone the repository

```bash
git clone https://github.com/ganeshkumar-133/Dussehra.git
cd Dussehra
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Start the development server

Navigate to the website application directory:

```bash
cd artifacts/durga-dussehra-story
```

On Windows PowerShell, run:

```powershell
$env:PORT="5173"
$env:BASE_PATH="/"
pnpm exec vite --config vite.config.ts --host 0.0.0.0
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
